落库设计 + RAG 问答时序图

模块 A/B/C 的数据表结构（Postgres + pgvector）· 模块 B「牧师问答」端到端 RAG 流程

一、落库设计（PostgreSQL + pgvector）

设计目标：权威原文可追溯、中文为绑定产出、向量可检索、审核可审计。所有 "来源" 表存英文原版；"中文" 表通过外键绑定来源主键，从机制上杜绝 "中文当来源"。

1.1 圣经（KJV 底本 + 中文产出 + 对照参照）

CREATE TABLE bible_book ( book_id SMALLINT PRIMARY KEY, book_code VARCHAR(8) NOT NULL UNIQUE, -- GEN, EXO, MAT ... book_name_en VARCHAR(64) NOT NULL, testament VARCHAR(8) NOT NULL, -- OT / NT position SMALLINT NOT NULL ); -- KJV 权威底本（逐节，唯一来源） CREATE TABLE bible_verse_kjv ( verse_id BIGSERIAL PRIMARY KEY, book_id SMALLINT NOT NULL REFERENCES bible_book(book_id), chapter SMALLINT NOT NULL, verse SMALLINT NOT NULL, text_kjv TEXT NOT NULL, UNIQUE (book_id, chapter, verse) ); -- 本应用中文译本（产出物，绑定原文） CREATE TABLE bible_verse_zh ( verse_id BIGINT PRIMARY KEY REFERENCES bible_verse_kjv(verse_id), text_zh TEXT NOT NULL, translator VARCHAR(64), glossary_ver VARCHAR(16), status VARCHAR(12) NOT NULL DEFAULT 'pending', -- pending/review/approved approved_by VARCHAR(64), approved_at TIMESTAMPTZ, content_ver VARCHAR(16) -- 内容版本号 ); -- 和合本：仅作「被观察的参照对象」，明确非来源 CREATE TABLE bible_verse_cuv_ref ( verse_id BIGINT PRIMARY KEY REFERENCES bible_verse_kjv(verse_id), text_cuv TEXT NOT NULL, ref_note TEXT -- 版权/引用说明 ); -- 对照释经注释（神学顾问撰写，对事不对人） CREATE TABLE comparison_note ( note_id BIGSERIAL PRIMARY KEY, verse_id BIGINT NOT NULL REFERENCES bible_verse_kjv(verse_id), note_zh TEXT NOT NULL, diff_type VARCHAR(16), -- wording/structure/theology author VARCHAR(64), status VARCHAR(12) NOT NULL DEFAULT 'pending', created_at TIMESTAMPTZ DEFAULT now() );

1.2 怀爱伦著作（EGW 原版 + 中文产出）

CREATE TABLE egw_work ( work_id VARCHAR(16) PRIMARY KEY, -- SC, GC, DA, MH ... title_en VARCHAR(128) NOT NULL, pub_year SMALLINT, public_domain BOOLEAN, -- 法务界定是否可作底本 license_note TEXT ); -- EGW 权威底本（逐段） CREATE TABLE egw_paragraph ( para_id BIGSERIAL PRIMARY KEY, work_id VARCHAR(16) NOT NULL REFERENCES egw_work(work_id), chapter_no SMALLINT, section_no SMALLINT, para_no SMALLINT, text_en TEXT NOT NULL, UNIQUE (work_id, chapter_no, section_no, para_no) ); -- EGW 中文（产出物） CREATE TABLE egw_paragraph_zh ( para_id BIGINT PRIMARY KEY REFERENCES egw_paragraph(para_id), text_zh TEXT NOT NULL, status VARCHAR(12) DEFAULT 'pending', approved_by VARCHAR(64), approved_at TIMESTAMPTZ );

1.3 教义条款（SDA 官方英文 + 中文）

CREATE TABLE doctrine_belief ( belief_no SMALLINT PRIMARY KEY, -- 1..28 title_en VARCHAR(128) NOT NULL, title_zh VARCHAR(128), text_en TEXT NOT NULL, -- 官方英文原版 text_zh TEXT, status VARCHAR(12) DEFAULT 'approved' );

1.4 统一检索分块 + 向量（RAG 核心）

-- 把 bible/egw/doctrine 的中英片段统一切片，供混合检索 CREATE TABLE content_chunk ( chunk_id BIGSERIAL PRIMARY KEY, source_type VARCHAR(12) NOT NULL, -- bible / egw / doctrine source_id VARCHAR(32) NOT NULL, -- verse_id / para_id / belief_no lang VARCHAR(4) NOT NULL, -- en / zh content TEXT NOT NULL, embedding VECTOR(1536), -- pgvector 维度随模型而定 created_at TIMESTAMPTZ DEFAULT now() ); CREATE INDEX idx_chunk_vec ON content_chunk USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100); CREATE INDEX idx_chunk_src ON content_chunk (source_type, source_id);

1.5 术语词典（译法一致约束）

CREATE TABLE glossary ( term_id SERIAL PRIMARY KEY, term_en VARCHAR(64) NOT NULL UNIQUE, -- justification ... term_zh VARCHAR(64) NOT NULL, -- 称义 ... definition_zh TEXT, domain VARCHAR(24) -- theology/health/doctrine );

1.6 审核 / 版本 / 审计（专家在环）

CREATE TABLE content_version ( version_id BIGSERIAL PRIMARY KEY, entity_type VARCHAR(16), -- bible_zh/egw_zh/doctrine/note entity_id VARCHAR(32), content_before TEXT, content_after TEXT, changed_by VARCHAR(64), change_reason TEXT, created_at TIMESTAMPTZ DEFAULT now() ); CREATE TABLE review_queue ( task_id BIGSERIAL PRIMARY KEY, entity_type VARCHAR(16), entity_id VARCHAR(32), status VARCHAR(12) DEFAULT 'open', -- open/approved/rejected assigned_to VARCHAR(64), note TEXT );

1.7 问答记录 + 强制引用 + 反馈

CREATE TABLE qa_session ( qa_id BIGSERIAL PRIMARY KEY, user_id VARCHAR(32), question_zh TEXT NOT NULL, answer_zh TEXT, confidence NUMERIC(3,2), -- 0.00~1.00 needs_human BOOLEAN DEFAULT false, -- 低置信转人工 model_used VARCHAR(32), created_at TIMESTAMPTZ DEFAULT now() ); -- 回答必须锚定权威片段（引用必填的落地） CREATE TABLE qa_citation ( qa_id BIGINT NOT NULL REFERENCES qa_session(qa_id), source_type VARCHAR(12) NOT NULL, -- bible / egw / doctrine source_id VARCHAR(32) NOT NULL, snippet TEXT, PRIMARY KEY (qa_id, source_type, source_id) ); CREATE TABLE qa_feedback ( feedback_id BIGSERIAL PRIMARY KEY, qa_id BIGINT REFERENCES qa_session(qa_id), feedback_type VARCHAR(16), -- correct/report/helpful comment_zh TEXT, routed_to VARCHAR(64), -- 进入顾问复核队列 created_at TIMESTAMPTZ DEFAULT now() );

1.8 用户与个性化（同步 / 离线）

CREATE TABLE app_user ( user_id VARCHAR(32) PRIMARY KEY, email VARCHAR(128) UNIQUE, display_name VARCHAR(64), created_at TIMESTAMPTZ DEFAULT now() ); CREATE TABLE user_bookmark ( bm_id BIGSERIAL PRIMARY KEY, user_id VARCHAR(32) REFERENCES app_user(user_id), source_type VARCHAR(12), source_id VARCHAR(32), note_zh TEXT, created_at TIMESTAMPTZ DEFAULT now() ); -- 健康打卡（模块 C，附医疗免责） CREATE TABLE health_log ( log_id BIGSERIAL PRIMARY KEY, user_id VARCHAR(32) REFERENCES app_user(user_id), log_date DATE NOT NULL, water_ml INTEGER, sleep_min INTEGER, exercise_min INTEGER, mood VARCHAR(12), note_zh TEXT );
关键约束（机制化防止「中文当来源」）：所有 *_zh 表的主键都是来源表外键（如 bible_verse_zh.verse_id → bible_verse_kjv.verse_id）；和合本单独存在 bible_verse_cuv_ref 中，不参与任何翻译或教义推理，仅在对照 UI 展示。检索与问答只从 content_chunk 取权威片段，引用回写 qa_citation 强制溯源。

实体关系速览

圣经域

bible_book 1—N bible_verse_kjv kjv 1—1 zh(产出) kjv 1—1 cuv_ref(参照) kjv 1—N comparison_note

EGW 域

egw_work 1—N egw_paragraph para 1—1 zh(产出)

教义域

doctrine_belief 1—N content_chunk

问答域

qa_session 1—N qa_citation qa_session 1—N qa_feedback citation → content_chunk(source)

二、模块 B「牧师问答」RAG 时序图

端到端流程：用户提问 → 混合检索权威片段 → 受控 LLM 生成（强制引用）→ 校验闸门 → 达标返回 / 不达标转人工 → 用户纠错闭环。

参与者：客户端 · 问答服务（含 API 网关）· 检索服务 · 向量库（pgvector）· LLM（受控生成）· 顾问队列（专家在环）

闸门逻辑（伪代码）

def answer(question_zh): hits = retrieval.hybrid_search(question_zh, top_k=8) # 向量 + 关键词 hits = rerank(hits, threshold=0.72) # 重排 + 阈值过滤 prompt = build_pastor_prompt(question_zh, hits) # 牧师人格 + 片段 + 引用约束 ans, cites, conf = llm.generate(prompt) if not cites or conf < 0.70: # 引用必填 + 置信不足 qa.needs_human = True review_queue.route(ans, hits) # 转顾问队列 return "建议咨询本地面牧者，问题已转交资深顾问复核" qa_citation.bulk_insert(qa_id, cites) # 强制溯源落地 return ans # 前端可一键展开 citation 原文出处
