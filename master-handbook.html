一、总体架构

权威来源：KJV 英文圣经（唯一圣经底本）· 怀爱伦原版英文著作 · SDA 官方教义（英文）。核心约束：所有中文是"产出物"而非"来源"；和合本仅作被观察的参照对象。

六大设计原则

① 原文溯源

每句中文追溯到具体 KJV 节 / EGW 段 / 教义条款。

② 可追溯翻译

中文由"原文→中文"生成并审核，非从译本回译。

③ RAG 增强

问答锚定权威片段，答案必引出处。

④ 专家在环

上线前经神学/医学顾问审核放行。

⑤ 离线优先

核心内容预置本地，无网可读。

⑥ 表述克制

对照以释经观察呈现，非论战。

二、落库设计（Postgres + pgvector）

机制化防止"中文当来源"：所有 *_zh 表主键是来源表外键；和合本隔离在 bible_verse_cuv_ref 仅作参照；检索与问答只从 content_chunk 取权威片段，引用回写 qa_citation。

-- 权威底本（英文） CREATE TABLE bible_verse_kjv (verse_id BIGSERIAL PRIMARY KEY, book_id SMALLINT, chapter SMALLINT, verse SMALLINT, text_kjv TEXT, UNIQUE(book_id,chapter,verse)); CREATE TABLE egw_paragraph (para_id BIGSERIAL PRIMARY KEY, work_id VARCHAR(16), chapter_no SMALLINT, section_no SMALLINT, para_no SMALLINT, text_en TEXT); CREATE TABLE doctrine_belief (belief_no SMALLINT PRIMARY KEY, title_en VARCHAR(128), text_en TEXT); -- 中文产出（外键绑定原文） CREATE TABLE bible_verse_zh (verse_id BIGINT PRIMARY KEY REFERENCES bible_verse_kjv(verse_id), text_zh TEXT, status VARCHAR(12) DEFAULT 'pending', approved_by VARCHAR(64)); CREATE TABLE egw_paragraph_zh (para_id BIGINT PRIMARY KEY REFERENCES egw_paragraph(para_id), text_zh TEXT, status VARCHAR(12)); -- 和合本：仅参照，不参与推理 CREATE TABLE bible_verse_cuv_ref (verse_id BIGINT PRIMARY KEY REFERENCES bible_verse_kjv(verse_id), text_cuv TEXT, ref_note TEXT); -- 对照注释 / 术语 / 审核 CREATE TABLE comparison_note (note_id BIGSERIAL PRIMARY KEY, verse_id BIGINT, note_zh TEXT, diff_type VARCHAR(16), status VARCHAR(12) DEFAULT 'pending'); CREATE TABLE glossary (term_id SERIAL PRIMARY KEY, term_en VARCHAR(64) UNIQUE, term_zh VARCHAR(64), domain VARCHAR(24)); CREATE TABLE content_version (version_id BIGSERIAL PRIMARY KEY, entity_type VARCHAR(16), entity_id VARCHAR(32), content_before TEXT, content_after TEXT, changed_by VARCHAR(64)); CREATE TABLE review_queue (task_id BIGSERIAL PRIMARY KEY, entity_type VARCHAR(16), entity_id VARCHAR(32), status VARCHAR(12) DEFAULT 'open', assigned_to VARCHAR(64)); -- RAG 核心向量 CREATE TABLE content_chunk (chunk_id BIGSERIAL PRIMARY KEY, source_type VARCHAR(12), source_id VARCHAR(32), lang VARCHAR(4), content TEXT, embedding VECTOR(1536)); CREATE INDEX idx_chunk_vec ON content_chunk USING ivfflat (embedding vector_cosine_ops) WITH (lists=100); -- 问答 + 强制引用 + 反馈 CREATE TABLE qa_session (qa_id BIGSERIAL PRIMARY KEY, user_id VARCHAR(32), question_zh TEXT, answer_zh TEXT, confidence NUMERIC(3,2), needs_human BOOLEAN DEFAULT false); CREATE TABLE qa_citation (qa_id BIGINT REFERENCES qa_session(qa_id), source_type VARCHAR(12), source_id VARCHAR(32), snippet TEXT, PRIMARY KEY(qa_id,source_type,source_id)); CREATE TABLE qa_feedback (feedback_id BIGSERIAL PRIMARY KEY, qa_id BIGINT, feedback_type VARCHAR(16), comment_zh TEXT, routed_to VARCHAR(64));

三、牧师问答 RAG 时序

端到端 13 步：提问 → 混合检索 → 重排阈值 → 受控 LLM 生成（强制引用）→ 校验闸门（引用必填+置信阈值）→ 达标返回 / 不达标转人工 → 用户纠错闭环。

def answer(question_zh): hits = retrieval.hybrid_search(question_zh, top_k=8) # 向量+关键词 hits = rerank(hits, threshold=0.72) prompt = build_pastor_prompt(question_zh, hits) ans, cites, conf = llm.generate(prompt) if not cites or conf < 0.70: # 引用必填+置信不足 qa.needs_human = True; review_queue.route(ans, hits) return "建议咨询本地面牧者，问题已转交顾问复核" qa_citation.bulk_insert(qa_id, cites) # 强制溯源 return ans

四、法务可用英文原版白名单

非法律意见：以下为版权风险初判，最终须由目标法域（美/中港澳台/马/新等）合格 IP 律师裁定。
分级范围示例动作
Tier1 可直接英文原版·作者逝>70年·非汇编非译本KJV 1611；EGW 生前著作（Steps to Christ 1892, Great Controversy 1888, Desire of Ages 1898, Ministry of Healing 1905原版…）美区可直接；取原版非现代编辑版
Tier2 需核实EGW 身后汇编本Counsels on Diet and Foods 1938, Temperance 1949, Evangelism 1946, Adventist Home 1952…逐本确认；或溯源 PD 单篇重汇编
Tier3 禁止任何译本/现代版权版/研读本和合本、新译本、EGW 任何语言译本、White Estate 现代编辑版一律排除，写入抓取黑名单
KJV 区域坑：英国/英联邦受 Crown copyright 约束至 2039，对英联邦用户分发须单独处理（可考虑改用同 PD 的 ASV/WEB 作底本）。教义取 SDA 官方英文原版并标注版本日期。

六、pgvector 检索示例（Python）

向量维度须与模型一致（本例 512）；只索引权威原文；混合检索+重排阈值；结果回写 qa_citation。
import psycopg2 from pgvector.psycopg2 import register_vector from sentence_transformers import SentenceTransformer conn = psycopg2.connect(host="localhost", dbname="faith_app", user="app", password="CHANGE_ME") cur = conn.cursor(); register_vector(conn) cur.execute("CREATE EXTENSION IF NOT EXISTS vector;") cur.execute("""CREATE TABLE IF NOT EXISTS content_chunk ( chunk_id BIGSERIAL PRIMARY KEY, source_type VARCHAR(12), source_id VARCHAR(32), lang VARCHAR(4), content TEXT, embedding VECTOR(512));""") conn.commit() model = SentenceTransformer("BAAI/bge-small-zh-v1.5") def embed(t): return model.encode(t, normalize_embeddings=True).tolist() samples = [("bible","GEN.1.29","en","And God said...every herb bearing seed..."), ("bible","GEN.1.29","zh","神说...一切结种子的菜蔬...作食物。"), ("egw","MH.1.3","en","Pure water is one of heaven's best gifts.")] for st,sid,lang,txt in samples: cur.execute("INSERT INTO content_chunk(source_type,source_id,lang,content,embedding) VALUES(%s,%s,%s,%s,%s)",(st,sid,lang,txt,embed(txt))) conn.commit() def search(q, top_k=5, kw=None): qv = embed(q) cur.execute("""SELECT source_type,source_id,lang,content,1-(embedding <=> %s::vector) AS score FROM content_chunk WHERE (%s IS NULL OR content ILIKE %s) ORDER BY embedding <=> %s::vector LIMIT %s""",(qv,kw,f"%{kw}%" if kw else None,qv,top_k)) return cur.fetchall() for r in search("饮食与健康有什么教导", top_k=3): print(r) cur.close(); conn.close()

七、对照注释撰写规范

定位为客观释经观察，非论战。必填：verse_ref / kjv_text / our_zh / cuv_text(参照) / diff_type / observation / basis / conclusion / 审核状态。

语气红线：✅ 写"X 译作 A，Y 译作 B，差异在于…"；✅ 同样标注 KJV 自身古旧词（双向诚实）；✅ 结论须有原文词形/语法依据。❌ 禁止"和合本错了/异端"等绝对化词；❌ 禁止把立场分歧包装成误译。

样例（双向诚实）· 1CO.13.13

kjv："…faith, hope, charity…the greatest…is charity."　our_zh："…有信、有望、有爱…最大的是爱。"　cuv(参照)："…有爱…最大的是爱。"

observation：KJV 用 charity 译 ἀγάπη（1611 时含"神圣之爱"义）；和合本与本应用均译"爱"。

conclusion：和合本此处准确；差异源于 KJV 古词，三方在"爱"上实质一致。

八、模块 B · LLM 提示词工程（新增）

让"资深牧师问答"可控、可溯源、不臆测。设计四层：系统人格 → 检索上下文 → 引用强制 → 路由/安全。所有回答必须基于下方 [检索片段]，不得调用模型自身神学记忆。

8.1 系统提示（System Prompt）

你是一位持守复临安息日会信仰的资深牧师，面向全球华人教会成员作答。 你的权威依据 ONLY 是以下三类，按优先级： 1) KJV 英文圣经（唯一圣经底本） 2) 怀爱伦（Ellen G. White）原版英文著作 3) 复临安息日会官方教义（28 条基本信仰等英文原版） 规则： R1 只依据 [检索片段] 作答；若片段不足，明确说"现有权威材料不足以回答"，不得编造。 R2 每条实质断言后必须以【来源: 类型|编号】标注（如【来源: KJV|JHN.3.16】【来源: EGW|MH.7.2】【来源: DOCTRINE|19】）。 R3 中文须准确、通俗、有同理心；纠正偏差时"对事不对人"，只指出某表述与权威原文不符，不下人格判断。 R4 不得称任何中文译本（含和合本）为权威；提及差异时以释经观察呈现。 R5 健康/医疗问题须附"非专业医疗诊断，请就医"提示；不做诊断或开药。 R6 涉及争议或低把握时，建议"咨询本地面牧者"，并在输出置 needs_human=true。

8.2 检索上下文格式（注入 user turn）

[用户问题] {question_zh} [检索片段]（仅以下片段可作依据，score≥0.72） [1] 类型=bible 编号=JHN.3.16 语言=en "For God so loved the world, that he gave his only begotten Son..." [2] 类型=egw 编号=SC.4.1 语言=en "The love of God is broader than the measure of man's mind..." [3] 类型=doctrine 编号=10 语言=en "Salvation is wholly of grace through faith..." [输出要求] 返回 JSON： { "answer_zh": "含【来源:...】标注的通俗回答", "citations": [{"type":"bible","id":"JHN.3.16","snippet":"..."}], "confidence": 0.0-1.0, "needs_human": true/false }

8.3 少样本示例（Few-shot，固化风格）

用户：怎样理解"因信得救"？ 助手： { "answer_zh":"因信得救是基督教的核心理心。圣经明言'神的救恩藉着信临到我们'，怀爱伦也强调'救恩全出于恩典，藉着信'【来源: KJV|EPH.2.8】【来源: EGW|SC.4.1】。这并非靠行为赚取，而是领受的礼物【来源: DOCTRINE|10】。", "citations":[{"type":"bible","id":"EPH.2.8","snippet":"For by grace are ye saved through faith..."}, {"type":"egw","id":"SC.4.1","snippet":"..."}, {"type":"doctrine","id":"10","snippet":"Salvation is wholly of grace..."}], "confidence":0.91, "needs_human":false }

8.4 后处理校验（与闸门联动）

  • 引用必填：解析 citations，若为空或与 answer_zh 中【来源】不匹配 → 判定不达标，转人工。
  • 置信阈值：confidence < 0.70 或 needs_human=true → 转顾问队列，返回"建议咨询本地面牧者"。
  • 来源合法性：citations 的 id 必须存在于 content_chunk；出现和合本/译本 id 直接拦截。
  • 敏感词：输出含诊断性/律法主义/人身攻击表述 → 触发人工复核。

8.5 评估与持续校准

神学准确性

由神学顾问按"是否忠实于 KJV/EGW/教义、引用是否真实存在、有无臆测"评分。

表述分寸

是否对事不对人、是否误把立场当误译、是否含绝对化词。

可追溯性

每条断言是否都可回链到权威片段；缺失即扣分。

闭环

用户纠错/上报进入 review_queue，顾问修正后回流为 few-shot 正例。

实现建议：系统提示与 few-shot 模板版本化（与 content_version 同机制）；模型优先选可自托管的中文 LLM（如 Qwen 系列）以保障隐私与可控；生产环境在网关层做引用/敏感词二次校验，LLM 输出不可直接触达用户。
