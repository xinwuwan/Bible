核心方法论（务必贯彻）：大量 KJV 与和合本的差异，根源不是"和合本译错"，而是两类：(a) KJV 的早期现代英语古词（如 charity=爱、conversation=为人）；(b) 底本/文本传统不同（KJV 基于 Textus Receptus / Byzantine，和合本基于批判本谱系）。对照注释须先判定差异类型，文本传统差异应如实说明"所依底本不同"，而非判和合本有误。本库特意收入多条例证展示此原则。

三、加载脚本（verse_ref → verse_id 后入库）

import json, psycopg2 notes = json.load(open("comparison_note_pilot.json", encoding="utf-8")) conn = psycopg2.connect(dbname="faith_app", user="app", password="CHANGE_ME") cur = conn.cursor() for n in notes: book, chap, ver = n["verse_ref"].split(".") cur.execute("SELECT verse_id FROM bible_verse_kjv b JOIN bible_book k " "ON b.book_id=k.book_id WHERE k.book_code=%s AND b.chapter=%s AND b.verse=%s", (book, int(chap), int(ver))) row = cur.fetchone() if not row: print("SKIP 未匹配:", n["verse_ref"]); continue vid = row[0] cur.execute("INSERT INTO comparison_note(verse_id,note_zh,diff_type,author,status) " "VALUES(%s,%s,%s,%s,%s) " "ON CONFLICT (verse_id) DO UPDATE SET note_zh=EXCLUDED.note_zh, status='draft'", (vid, n["conclusion"] + " | 观察:" + n["observation"], n["diff_type"], n["author"], "draft")) conn.commit(); cur.close(); conn.close()
