一、给法务的可用英文原版白名单

性质声明：本清单为工程与产品侧的版权风险初判，不构成法律意见。最终可用性必须由具备相关司法辖区资格的知识产权律师裁定，尤其在美、中（含港澳台）、东南亚（马来西亚 / 新加坡）等目标市场。

1.1 分级原则

Tier 1 可直接用

英文原版、作者逝世超 70 年、且非身后汇编 / 非译本。抓取前仍做单本确认。

Tier 2 需逐本核实

身后由 White Estate 编纂的汇编本 / 现代带版权版本，版权状态随本、随法域而异。

Tier 3 绝对禁止

任何语言译本（含和合本及 EGW 中文版）、第三方研读本、带新版权的现代编辑本。

区域特例

KJV 在英国 / 英联邦受 Crown copyright 约束，全球分发需单独评估。

1.2 Tier 1 · KJV 圣经（权威底本）

材料类型出版预计版权可用区域法务动作
KJV (1611) 经文文本 圣经原文（英文） 1611 公共领域 美国及多数法域 PD 美区可直接用；英国 / 英联邦注意 Crown copyright（至 2039），对英联邦用户分发需单独许可或规避
KJV 区域坑：在英国与部分英联邦国家，KJV 文本受英国王室版权（Royal Letters Patent）保护，Cambridge / Oxford UP 为授权印厂，保护期至 2039 年。一个"全球"应用若向英国用户推送 KJV 全文，可能触发该权利。建议：英美分别处理，或对英联邦用户改用同样 PD 的英文译本（如 ASV / WEB）作为底本，并在法务确认后统一。

1.5 Tier 3 · 绝对禁止直接使用

  • 任何中文译本：和合本、新译本、吕振中、思高本，以及 EGW 任何语言译本——既受版权约束，也违反"不以中文译本为来源"的核心原则。
  • 现代带版权版本：White Estate 的现代编辑本、带导言 / 注释的研究版、出版社重排本。
  • 第三方研读本 / 串珠本：含他人注释、 cross-reference 的版本。
  • 未授权抓取：任何未获明确授权的网站全文。

二、健康模块 NEWSTART 内容表结构

NEWSTART 八大支柱：Nutrition 营养 · Exercise 运动 · Water 水 · Sunlight 阳光 · Temperance 节制 · Air 空气 · Rest 休息 · Trust 信靠。每条都须绑定权威来源（圣经 + EGW + 教义），且经医学顾问审核，附医疗免责。

2.1 健康主题（八大支柱）

CREATE TABLE health_topic ( topic_code VARCHAR(8) PRIMARY KEY, -- NUT/EXE/WAT/SUN/TEM/AIR/RES/TRU topic_name_en VARCHAR(32) NOT NULL, topic_name_zh VARCHAR(32) NOT NULL, summary_zh TEXT, order_no SMALLINT );

2.2 主题权威来源绑定（溯源到 bible/egw/doctrine）

CREATE TABLE health_topic_source ( topic_code VARCHAR(8) NOT NULL REFERENCES health_topic(topic_code), source_type VARCHAR(12) NOT NULL, -- bible / egw / doctrine source_id VARCHAR(32) NOT NULL, -- verse_id / para_id / belief_no relevance_zh TEXT, -- 该来源与主题的关联说明 PRIMARY KEY (topic_code, source_type, source_id) );

2.3 结构化健康指导条目（医学顾问审核）

CREATE TABLE health_guidance ( guidance_id BIGSERIAL PRIMARY KEY, topic_code VARCHAR(8) NOT NULL REFERENCES health_topic(topic_code), title_zh VARCHAR(120) NOT NULL, body_zh TEXT NOT NULL, evidence_level VARCHAR(12), -- strong/moderate/traditional medical_reviewed BOOLEAN DEFAULT false, -- 医学顾问放行闸 disclaimer_zh TEXT, -- “非专业医疗诊断”声明 status VARCHAR(12) DEFAULT 'pending' );

2.4 可追踪指标定义（对应打卡）

CREATE TABLE health_metric ( metric_code VARCHAR(12) PRIMARY KEY, -- water_ml/sleep_min/exercise_min/sunlight_min/mood topic_code VARCHAR(8) REFERENCES health_topic(topic_code), unit VARCHAR(8), target_daily VARCHAR(32), -- 建议目标，如 "1500-2000ml" note_zh TEXT );

2.5 用户打卡（细化自 health_log）

CREATE TABLE health_log_entry ( entry_id BIGSERIAL PRIMARY KEY, user_id VARCHAR(32) REFERENCES app_user(user_id), log_date DATE NOT NULL, metric_code VARCHAR(12) REFERENCES health_metric(metric_code), value NUMERIC, note_zh TEXT, created_at TIMESTAMPTZ DEFAULT now(), UNIQUE (user_id, log_date, metric_code) -- 同日同指标仅一条 );

2.6 八支柱与指标 / 来源映射示例

医学边界：health_guidance 一律带 medical_reviewed=false 不可发布；disclaimer_zh 必须含"本内容为指导性建议，不构成专业医疗诊断，疾病请及时就医"。指标目标值（如饮水、睡眠）仅作温和建议，不得给出诊断性或治疗性结论。

2.7 与既有表的关系

溯源一致

health_topic_source 复用 bible_verse_kjv / egw_paragraph / doctrine_belief 的主键，与模块 A/B 共用同一权威库，保证"健康建议也能一键展开原文出处"。

审核一致

health_guidance.status 与 medical_reviewed 复用模块 A 的审核 / 版本机制，进入同一 review_queue。
